# Open Idea website

Static site for **Open Idea** (Ecosyz Core Solutions Pvt. Ltd.). Plain HTML/CSS/JS, no framework.

- `index.html` – home page
- `services.html`, `products.html` – sub pages, generated by `python3 gen.py` from the shared header/footer in `index.html`
- `css/site.css`, `js/site.js` – shared styles and scripts (edit these). `release.py` minifies them to `*.min.*` and stamps `?v=` versions into the pages
- `fonts/`, `js/vendor/` – self-hosted fonts and GSAP/ScrollTrigger/Lenis (no third-party requests)
- `img/`, `media/` – all images and videos (permanent copies, no external asset links)

## Hero media
The hero has one hands video per theme: `.hv-light` and `.hv-dark` in `index.html`. Each `<video>` has `data-reveal` (seconds): the hero text fades in when the clip reaches that moment.

## Release
`python3 release.py path/to/esbuild` (regenerates sub pages, minifies, versions assets). `vercel.json` sets long cache headers.

## Lives at openidea.co.in/techpartner
The Vercel build runs `tools/basepath.py`, which writes the site to `public/techpartner/` with absolute `/techpartner/...` paths and a canonical URL on openidea.co.in. The main openidea.co.in app proxies `/techpartner` here with a rewrite.

## Deploy (Vercel)
Vercel project `open-idea` builds by downloading this repo at a pinned commit into `public/`.
